🎮 Clash of Games v1.6 Update is Live! 🚀
📅 Last Update On: [Friday, November, 06, 2026]
Here is what is new and improved in this version:
💬 Private Chat
​Players can now send personal direct messages to each other alongside Global Chat!
​⚠️ Note: Please keep in mind that this chat feature is not end-to-end encrypted.
🌍 Global Chat - New Features & Improvements
​⚡ Playback Speed: Added playback speed controls for voice messages.
​🎯 Smart Scroll & Highlight: Clicking on a selected reply will now auto-scroll directly to the target message and highlight it.
​↗️ Voice Message Sharing: Voice messages can now be shared easily.
🐛 Bug Fixes
​Fixed an issue where voice message replies were not showing the correct mention tag.
